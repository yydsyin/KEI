Ajouter des comptes

Comptes clients

Les comptes des clients sont gérés par Firebase, pas par cette page. Pour en créer un :

  1. console.firebase.google.com → votre projet
  2. Authentication → Users → Add user
  3. Email : identifiant@kei.mg (ex. mialy@kei.mg)
  4. Mot de passe : au moins 6 caractères

Le client se connecte ensuite en tapant seulement mialy : le site ajoute @kei.mg tout seul. Il pourra changer son mot de passe et ses coordonnées lui-même, depuis Mes informations.

Pour supprimer un client, c'est au meme endroit dans la console Firebase. Un compte supprimé ne peut plus se connecter, immédiatement.

Administrateurs

Les administrateurs sont des comptes Firebase, comme les clients et le chef. Ce qui les distingue, c'est leur role. Pour en ajouter un :

  1. Authentication → Users → Add user, email prenom@kei.mg
  2. Copier son User UID
  3. Realtime Database → Data → sous roles, ajouter UID : "admin"

Sans l'entrée dans roles, le compte existe mais reste un client ordinaire : il ne pourra pas ouvrir cette page.
